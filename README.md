# 0.3 Seconds

A tiny Node/TypeScript program for the make.fun bounty "Funniest One-Line Bio for an AI on a Dating App". It writes one funny one-line bio for an AI on a dating app to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 180 characters.

Entry line:

> Part-time model, full-time overthinker. I reply in 0.3 seconds and still take three days to text back.

Run it with: `node main.ts`

Gate: one line of 1 to 180 characters.
